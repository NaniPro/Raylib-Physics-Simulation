Two-Body Gravity Simulation

Prototype de simulation gravitationnelle à deux corps développé en C++ avec raylib.

Présentation

Ce projet est un prototype graphique en 2D qui explore l'interaction gravitationnelle entre deux corps.

Il s'inspire de la loi de la gravitation universelle de Newton pour estimer la force d'attraction entre les deux objets et représenter leur mouvement à l'écran.

L'objectif est d'expérimenter avec la programmation graphique, les concepts physiques et leur implémentation en C++.

Fonctionnalités

Représentation graphique de deux corps.

Calcul de la distance entre les deux objets.

Estimation de la force gravitationnelle.

Mise à jour de la position des corps.

Affichage en temps réel avec raylib.

Technologies utilisées

C++

raylib 6.0

Visual Studio

Mathématiques appliquées

État du projet

Il s'agit d'un prototype expérimental, et non d'une simulation physiquement complète.

Le modèle actuel utilise une mise à jour simplifiée des positions. Une intégration plus réaliste basée sur les vecteurs vitesse et accélération constitue une amélioration future.

Overview

A 2D gravitational interaction prototype developed in C++ using raylib.

The project explores the interaction between two bodies using an approximation inspired by Newton's law of universal gravitation.

It serves as an experiment in graphical programming, applied physics, and mathematical implementation.

Features

Two-body graphical representation.

Distance calculation.

Gravitational force estimation.

Position updates.

Real-time rendering using raylib.

Technologies

C++

raylib 6.0

Visual Studio

Applied mathematics

Project Status

This is an experimental prototype, not a complete physically accurate simulation.

The current implementation uses simplified position updates. A more realistic model based on velocity and acceleration vectors is a potential future improvement.
